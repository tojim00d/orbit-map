# Changelog

## 1.0.0 — 2026-11-09

- First standalone release of the two map and diagram skills from the Orbit pack.
- `project-map`: interactive one-file HTML project map with code links, auto-layout, step numbers in reading order, EN/RU UI and an offline build script.
- `project-diagram`: static SVG/PNG phase diagrams in blueprint and paper themes.
- Claude Code plugin install (`orbit-map@orbit-map`) plus `--skills-dir` for other agents.
- Published demo page with the example map.
