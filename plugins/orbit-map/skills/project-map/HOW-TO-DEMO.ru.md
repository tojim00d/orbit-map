# Как показать project-map за 5 минут

[English](HOW-TO-DEMO.md) · **Русский**
## 1. Готовый пример (30 секунд)
Открой `example/project.html` двойным кликом. Покажи:
- фазы ①②③ сверху вниз и номера шагов 1→12 по ходу чтения;
- толстые стрелки с кольцом — переходы между фазами, пунктир «новый виток» по краю;
- клик по блоку, чипу или номеру — карточка с подробностями и ссылками на код;
- вкладку «Блок-схема» — тот же проект колонками.

## 2. Карта любого проекта
**Вариант А — одной фразой.** В Claude Code, в корне репозитория:
```
Построй карту проекта скиллом project-map в docs/project-map/
```

**Вариант Б — руками за 5 команд.** После установки скилл лежит в `${CLAUDE_PLUGIN_ROOT}/skills/project-map`:
```bash
mkdir -p docs/project-map && cd docs/project-map
cp "${CLAUDE_PLUGIN_ROOT}/skills/project-map/assets/{project.template.html,project-schema.js,project-view.js,build.py}" .
cp "${CLAUDE_PLUGIN_ROOT}/skills/project-map/assets/project-data.starter.js" project-data.js
# отредактируй project-data.js: блоки N, связи E, порядок LAYOUT
python3 build.py && open project.html
```

## 3. Что сказать на демо
- «Один HTML-файл, открывается двойным кликом, публикуется как статическая страница».
- «Под проект правится один файл с данными, раскладку движок делает сам».
- «Номера шагов идут по ходу чтения, переходы между фазами видно сразу».
- «Каждый блок и связь ведут в код — карта проверяется, а не рисуется по памяти».

## 4. Как получить самую чистую схему
- Фазы — по потоку сверху вниз, внутри фазы блоки в порядке шагов слева направо.
- До ~15 связей на схеме, подписи стрелок — 1–3 слова.
- Нужна картинка для слайда — скилл `project-diagram`.
